# Supplementary materials

This repository contains the supplementary materials associated with the study titled:

**SONJON Y., CHARRIAU A., MOUHOUB D., VAN DER HENST J-B., CHABANAT E. Negotiating the social self in chronic spinal pain: a qualitative study. Preprint. DOI: [to be added upon deposit]**

## Overview

This repository contains supplementary methodological and analytic materials associated with the study. It does not contain the complete interview transcripts.

---

## Contents

### 1. Interview guide

`Supplementary_Material_1_Interview_Guide_FR.pdf`

Original French semi-structured interview guide used for data collection.

Interviews were conducted in French.

### 2. Codebook

`Supplementary_Material_2_Codebook_EN.pdf`

English-language version of the final codebook corresponding to the final analytic structure reported in the manuscript.

The codebook is organised hierarchically into:

- **Categories**: the broadest analytical level;
- **Codes**: analytical processes or phenomena grouped within each category;
- *Sub-codes*: more specific processes nested within a code.

For each category, code, and sub-code, the table provides:

- an operational definition;
- **Interviews**: the number of participant interviews in which the category,
  code, or sub-code was identified;
- **Segments**: the total number of coded data segments assigned to that
  category, code, or sub-code.

Categories are shown in **bold**, codes in regular type, and sub-codes in
*italics*.

The numerical counts are provided to document the distribution of the coding across the dataset. They should not be interpreted as measures of prevalence, importance, or effect size.
For parent codes, segment counts include the segments assigned to their nested sub-codes and should therefore not be summed across hierarchical levels.

### 3. Supporting quotations

`Supplementary_Material_3_Supporting_Quotes_FR_EN.ods`

Original French quotations corresponding to participant quotations translated into English and reported in the Results section of the manuscript.

The file provides the English translation used in the manuscript alongside the original French quotation.

### 4. High-resolution codebook diagram

`Supplementary_Material_4_Codebook_Diagram_High_Resolution.svg`

High-resolution version of the codebook diagram presented in the manuscript.

### 5. High-resolution central process diagram

`Supplementary_Material_5_Central_Process_Diagram_High_Resolution.svg`

High-resolution version of the central process diagram presenting the central process identified in the analysis.

## Data availability and confidentiality

Complete interview transcripts are not publicly available because they contain potentially identifiable qualitative information and unrestricted public sharing was not included in the conditions under which the data were collected.

The repository therefore contains only the methodological and analytic materials necessary to support interpretation and transparency of the published study, together with the original-language versions of quotations reported in the manuscript.
